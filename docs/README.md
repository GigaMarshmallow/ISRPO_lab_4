# Geometric Lib


## Описание
Geometric Lib — библиотека для вычисления площадей и периметров геометрических фигур.


## Функции
### Круг (circle.py)
- `area(r)` - площадь круга.

    Формула: S = πR²
    
    Пример: area(3) -> 28.274333882308138

- `perimeter(r)` - периметр круга.

    Формула: P = 2πR

    Пример: perimeter(3) -> 18.84955592153876


### Прямоугольник (rectangle.py)
- `area(a, b)` - площадь прямоугольника.

    Формула: S = ab

    Пример: area(4, 5) -> 20

- `perimeter(a, b)` - периметр прямоугольника.

    Формула: P = 2a + 2b

    Пример: perimeter(4, 5) -> 18


### Квадрат (square.py)
- `area(a)` - площадь квадрата.

    Формула: S = a²

    Пример: area(5) -> 25

- `perimeter(a)` - периметр квадрата.

    Формула: P = 4a

    Пример: perimeter(5) -> 20


### Треугольник (triangle.py)
- `area(a, h)` - площадь треугольника.

    Формула: S = (ah)/2

    Пример: area(4, 5) -> 10

- `perimeter(a, b, c)` - периметр треугольника.

    Формула: P = a + b + c

    Пример: perimeter(4, 5, 6) -> 15

## Пример функции
```python
def perimeter(a):
    """
    Вычисляет периметр квадрата по заданной длине стороны.

    Параметры:
        a (float): длина стороны

    Возвращаемое значение:
        float: периметр квадрата

    Пример вызова:
        perimeter(5) -> 20
    """
    return 4 * a
```
